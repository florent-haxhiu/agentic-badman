# Appendix: Agent Prompts Library

This section contains the full system prompts for all sample teams. Use these as your starting point — whether you're configuring a Harness or understanding what the sample code does.
Each prompt follows the same proven structure:
1. — who the agent is and what it does
2. — position-specific behavior
3. — the full command reference
4. — spatial awareness
5. — exact JSON schema expected
All prompts share the same command reference and response format. The only difference between teams is the Role section — that's where the strategy lives.
| Team | Strategy | Risk Level |
| [⚖️ Balanced](/agentic-football/en-US/agent-prompts/balanced/) | Solid all-round play. GK stays deep, defender holds shape, midfielder links, forwards attack. | Low |
| [🔥 Aggressive](/agentic-football/en-US/agent-prompts/aggressive/) | All-out attack. GK pushes to midfield, defender joins attacks, everyone shoots from distance. | High |
| [🛡️ Defensive](/agentic-football/en-US/agent-prompts/defensive/) | Park the bus. Everyone stays deep, forwards track back, minimal attacking. | Low |

Start with Balanced
for your first deployment. Once you've played a match, try Aggressive or Defensive to see how different strategies perform — or mix and match prompts from different teams to create your own hybrid.
